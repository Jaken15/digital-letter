OUR STORY — ROMANTIC SCRAPBOOK

Paano patakbuhin:
1. I-extract ang ZIP.
2. Buksan ang folder sa VS Code.
3. Buksan ang index.html sa browser, o gamitin ang VS Code Live Server extension.
4. Kailangan ng internet para sa Google Fonts at sample photos.

Mga file:
- index.html : structure at laman ng website
- style.css  : colors, layout, responsive design, hover effects, modals
- script.js  : pag-click sa photos, next/previous, at love letter modal

Pagpapersonalize:
- Palitan ang captions, dates, at love letter sa index.html.
- Para palitan ang larawan, palitan ang URL ng img src sa index.html at ang kaugnay na src sa memories array sa script.js.
- Mas mainam ang sariling larawan ninyo. Maaari mong ilagay ang mga larawan sa folder na images/ at gamitin ang paths na images/memory-1.jpg.
- Ang dates at sample messages ay placeholders; palitan ang mga ito ng tunay ninyong memories.
